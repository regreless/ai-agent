# 「通用型智能体和普通AI对话有什么区别？」

- 通用型智能体和普通对话机器人的核心区别在于有没有 Planning
  能力。普通对话机器人是被动响应，接收输入生成输出，没有主动执行目标的能力。通用型智能体是目标驱动的，给它一个自然语言描述的目标，它会自主拆解成子任务，动态选择工具执行，遇到问题自动回退，最后交付结果。

- 架构上，通用型智能体有六层：用户入口层做安全校验，持久化层保证上下文连续，编排层负责 Planning 和任务调度，子智能体层按角色并行执行，工具和
  Skill 层完成实际操作，最底层是大模型。大模型在这里只是规划器，真正干活的是工具和 Skill 层。

5. 用户中途改要求，原计划重排还是废弃？

5. 支付、删数据等高风险操作，何时必须用户确认？
